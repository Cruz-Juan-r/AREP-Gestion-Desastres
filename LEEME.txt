CONTENIDO
  sistema_gestion_desastres.pdf ... documento compilado (ESTE es el que se lee)
  documento/ ...................... código fuente LaTeX del documento
     sistema_gestion_desastres.tex   documento principal
     seccion_prototipo.tex           sección 7: prototipo (se incluye con \input)
     tabla_resultados.tex            tabla de resultados (la genera el experimento)
     figuras/                        PNG que usa el .tex
     diagramas-c4/                   fuentes .puml, PNG y SVG de los diagramas C4
  prototipo-edge/ ................. código fuente del prototipo (ver su README.md)
     edge-node/, cloud-api/, shared/   servicios reales en Java 21 + Spring Boot 3 (Maven, mvnw)
     simulator/, wan/, experiment/     herramientas de prueba en Python

COMPILAR EL DOCUMENTO
  cd documento
  pdflatex sistema_gestion_desastres.tex   (dos veces, para el índice)
  En Overleaf: subir la carpeta documento/ completa y compilar con pdfLaTeX.

EJECUTAR EL PROTOTIPO
  cd prototipo-edge
  docker compose up --build -d                              -> http://localhost:8080
  docker compose --profile experiment run --rm experiment   -> repite el experimento
  Pruebas unitarias (JUnit): mvnw.cmd verify   (en Linux/macOS: ./mvnw verify)
  Sin Docker: mvnw.cmd -DskipTests package, pip install -r requirements.txt
              y python scripts/run_local_stack.py
